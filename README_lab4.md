# Лабораторная работа №4 — Основы JavaScript

## Тема
Знакомство с синтаксисом JavaScript, базовыми конструкциями и логикой: ввод/вывод, условия, циклы и функции.

## Описание
В рамках лабораторной работы к странице из предыдущих лабораторных работ был подключён скрипт `script.js`, который обрабатывает массив данных и выводит результат через `alert` и `console.log`.

Скрипт реализует:

* ввод имени пользователя через `prompt`;
* приветствие и итоговое сообщение через `alert`;
* вывод дополнительной информации через `console.log`;
* условные конструкции;
* цикл по массиву;
* функции для поиска максимума, фильтрации и подсчёта суммы.

## Вариант работы
Вариант 2. Тема «Путешественник» (расстояния в км).

Данные: массив из 7 чисел — расстояния между городами в одном маршруте: `[120, 25, 340, 18, 150, 30, 85]`.

Логика:

* функция `filterLongRoutes` оставляет перегоны длиннее 100 км («длинные перегоны»);
* цикл проходит по массиву и подсчитывает количество коротких перегонов (≤ 30 км), а также отдельно суммирует их длину;
* функция `findMaxDistance` находит самый длинный перегон;
* функция `calculateTotalDistance` считает общую длину маршрута.

Вывод:

* через `alert` — приветствие с именем и фраза «Ваш маршрут длиной Z км, из них X км – длинные перегоны»;
* через `console.log` — количество коротких перегонов и их суммарная длина;
* дополнительно: если общая длина больше 500 км, в консоль выводится рекомендация «Рекомендуется разбить маршрут на 2–3 дня».

Результат для текущих данных:

* `alert`: «Ваш маршрут длиной 768 км, из них 610 км – длинные перегоны»;
* количество коротких перегонов: 3;
* суммарная длина коротких перегонов: 73 км;
* самый длинный перегон: 340 км;
* рекомендация разбить маршрут на 2–3 дня (общая длина 768 км > 500 км).
