# Лабораторная работа №5 — DOM и взаимодействие с элементами страницы

## Тема
Работа с DOM-деревом: поиск элементов, изменение содержимого, атрибутов и классов, добавление и удаление элементов, сохранение состояния страницы в `localStorage`.

## Описание
В рамках лабораторной работы к странице из предыдущих лабораторных работ был подключён скрипт `dom.js`, который делает страницу интерактивной: пользователь управляет списком навыков, переключает тему оформления и скрывает блоки. Все изменения происходят без перезагрузки страницы и сохраняются между перезагрузками.

Скрипт реализует:

* поиск элементов через `getElementById`, `querySelector` и `querySelectorAll`;
* изменение текста (`textContent`), атрибутов (`setAttribute`) и классов (`classList`);
* создание элементов через `createElement` и добавление через `appendChild`, удаление через `remove()`;
* переключение светлой и тёмной темы;
* скрытие и показ блока по клику;
* проверку существования элементов и вывод сообщений об ошибках в консоль;
* сохранение и восстановление состояния через `localStorage`.

## Вариант работы
Вариант 2. Тема «Путешественник» (управление навыками для поездок).

Контент: маркированный список навыков, каждый пункт — `<li>` с текстом и кнопкой «Удалить».

Логика:

* кнопка «Добавить навык» запрашивает название через `prompt`, создаёт `<li>` с текстом и кнопкой «Удалить» (обработчик удаляет именно этот `<li>`) и вставляет его в `<ul>` через `appendChild`;
* кнопка «Очистить навыки» находит все `<li>` через `querySelectorAll`, в цикле вызывает `remove()` у каждого; если список пуст, показывает `alert` «Навыки уже удалены»;
* отдельная кнопка переключает тёмную и светлую тему добавлением и удалением класса `dark` у `<body>`; текст кнопки меняется на «Светлая тема» или «Тёмная тема»;
* кнопка «Скрыть список навыков» добавляет класс `invisible` блоку со списком, повторное нажатие возвращает видимость; текст кнопки и атрибут `aria-expanded` меняются;
* обработка ошибок: перед работой проверяется наличие списка и кнопок, если элемента нет, в консоль выводится «Элемент не найден: #id», и функция завершается.

Сохранение состояния:

* список навыков хранится в `localStorage` под ключом `travelSkills` и обновляется при каждом добавлении, удалении и очистке;
* выбранная тема хранится под ключом `travelTheme`;
* при загрузке страницы список и тема восстанавливаются; если сохранённых данных нет, показываются навыки по умолчанию; пустой список после очистки тоже восстанавливается пустым;
* повреждённые данные в хранилище не ломают страницу.

Название навыка вставляется как текст (`textContent`), а не как HTML, поэтому разметку через `prompt` на страницу внедрить нельзя.

## Использованные технологии

* HTML5
* CSS3 (CSS-переменные, тёмная тема)
* JavaScript (ES6, DOM API, localStorage)

## Запуск проекта
Открыть файл `index.html` в любом современном браузере. Блок «Мой список навыков» находится в секции «Навыки», кнопка темы — в шапке страницы. Скрипт `script.js` из лабораторной работы №4 при загрузке спрашивает имя.
