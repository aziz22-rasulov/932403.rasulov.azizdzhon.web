# Лабораторная работа №3. Flexbox и CSS Grid, адаптивная вёрстка

**Цель:** освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

## Задание
Дополнить макет страницы из предыдущих работ:
- Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в ряд.
- Grid: галерея/дашборд (2–3 колонки, 2–3 строки).
- Медиа-запросы для планшетов и мобильных; отсутствие горизонтальной прокрутки.
- Контрастность ≥ 4.5:1; семантически верные теги для карточек.

## Вариант 2. Тема «Путешественник» (навыки и прогресс-дашборд)
- Flex-карточки «Навыки» (3–4 навыка, полезных в путешествиях: навигация, языки, фотография и т. п.; внутри карточки — прогресс-бар через `<div>` с `width` в процентах).
- Для Flex: `flex-direction: column` внутри карточки и `flex-wrap: wrap` для ряда карточек.
- Grid-дашборд «Статистика прогресса» (3 блока: «Страны», «Города», «Фото» — сетка 3×1 на десктопе, 1×3 на мобильном).
- Адаптивность: карточки — 1/2/4 колонки; Grid — 1 колонка на мобильном, 3 на остальных экранах.
- В семантике — `<dl>` (`dt`/`dd`) внутри карточек для пар «Навык / Уровень».
- Для прогресс-баров — контрастные цвета (оранжевый на тёмно-сером фоне).

## Что реализовано
- **Flexbox:**
  - Навигационное меню — горизонтальное, адаптивное (`display: flex; flex-wrap: wrap`), липкое (`position: sticky`).
  - Секция «Навыки» — 4 карточки: «Навигация по карте» (90%), «Иностранные языки» (75%), «Фотография» (65%), «Выживание в дикой природе» (55%).
  - Контейнер `.skill-cards` — `display: flex; flex-wrap: wrap`; внутри каждой карточки `.skill-card` — `flex-direction: column`.
  - Каждая карточка — элемент списка `<li>` с `<dl>`: пары `<dt>Навык</dt><dd>…</dd>` и `<dt>Уровень</dt><dd>…%</dd>`.
  - Прогресс-бар — `<div class="progress-track">` с вложенным `<div class="progress-fill">`, ширина заполнения задана в процентах (`style="width: 90%;"`).
- **CSS Grid:**
  - Новая секция «Статистика прогресса» (`id="progress"`) с тремя блоками: «Страны» (3), «Города» (9), «Фото» (240).
  - Контейнер `.stats-grid` — `display: grid; grid-template-columns: repeat(3, 1fr)`; на мобильном — одна колонка (`1fr`).
- **Адаптивность (медиа-запросы):**
  - `max-width: 900px` (планшеты) — карточки навыков в 2 колонки.
  - `max-width: 780px` — основная раскладка и боковая панель перестраиваются в одну колонку.
  - `max-width: 600px` (мобильные) — карточки навыков в 1 колонку, grid-дашборд в 1 колонку.
  - `max-width: 500px` — шапка выстраивается в столбик.
  - Горизонтальная прокрутка исключена: `html { overflow-x: hidden }`, `img { max-width: 100%; height: auto }`, `box-sizing: border-box`.
- **Контрастность:**
  - Текст карточек и дашборда использует `--ink`, `--muted` и `--rust-dark`, контраст с фоном не менее 4.5:1.
  - Прогресс-бар — оранжевый (`--rust`) на тёмно-сером фоне (`#3a332c`).
- **Семантика:**
  - Карточки и блоки статистики — элементы списков `<ul>/<li>`.
  - Пары «Навык / Уровень» — `<dl>/<dt>/<dd>`.
  - Каждая секция связана с заголовком через `aria-labelledby`.
- В навигацию добавлен пункт «Прогресс».
