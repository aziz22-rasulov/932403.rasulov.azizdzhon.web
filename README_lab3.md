# Лабораторная работа №3 — Flexbox и CSS Grid, адаптивная вёрстка

## Тема
Адаптивный макет персональной HTML-страницы студента с использованием Flexbox и CSS Grid.

## Описание
В рамках лабораторной работы страница из лабораторных работ №1 и №2 была дополнена одномерными (Flexbox) и двумерными (CSS Grid) макетами, а также адаптивной вёрсткой с помощью медиа-запросов.

На странице представлены:

* шапка сайта с именем студента;
* липкая адаптивная навигационная панель;
* карточки навыков с прогресс-барами;
* список посещённых стран;
* дашборд «Статистика прогресса»;
* секция «Проекты»;
* форма обратной связи;
* боковая информационная панель с изображением;
* подвал страницы.

## Вариант работы
Вариант 2. Тема «Путешественник» (навыки и прогресс-дашборд): навыки оформлены в виде Flex-карточек, внутри каждой карточки находится прогресс-бар (`<div>` с `width` в процентах). Для карточек использованы `flex-direction: column` и `flex-wrap: wrap`. Дашборд «Статистика прогресса» (блоки «Страны», «Города», «Фото») реализован на CSS Grid: сетка 3×1 на десктопе и 1×3 на мобильном. Пары «Навык / Уровень» оформлены через `<dl>` (`dt`/`dd`). Прогресс-бары выполнены в контрастных цветах: оранжевый на тёмно-сером фоне. Цветовая гамма: бежево-оранжевая.

Адаптивность:

* карточки навыков: 4 колонки на десктопе, 2 на планшете (до 900px), 1 на мобильном (до 600px);
* Grid-дашборд: 3 колонки на десктопе и планшете, 1 колонка на мобильном (до 600px);
* горизонтальная прокрутка отсутствует;
* контрастность текста не менее 4.5:1.

## Использованные технологии

* HTML5
* CSS3 (Flexbox, CSS Grid, медиа-запросы, CSS-переменные)

## Запуск проекта
Открыть файл `index.html` в любом современном браузере.
